# Rove 如晤 · 共同在场技术原型

把 Rove 的研究概念推进为可以运行、测试和继续接设备的第一条技术链路：

**创建主场 → 接受邀请 → 双人共享空间 → 头手位置同步 → 共同观看 → 可选音视频 → 逐次确认触碰 → 退出与清理。**

当前为 **v0.1 桌面浏览器联调原型**。已经实现房间服务和客户端代码；程序化房间、简化化身和默认视觉触碰用于验证链路。真实房间扫描、真人重建、AR/VR 头显和实体触觉腕带需要下一阶段接入与实测。请先读 [验证记录](docs/VALIDATION.md)，区分运行过的测试与尚未验证的设备能力。

## 快速运行

需要 Node.js **22.12 或更高版本**，推荐使用已维护的 Node.js 22/24 环境。

```bash
npm ci
npm run dev
```

浏览器打开 `http://127.0.0.1:5173`。不需要数据库、模型 API Key、摄像头或头显，即可创建房间并试用桌面空间。

构建后运行：

```bash
npm run build
npm start
```

`npm start` 提供构建后的 `dist/` 与实时服务。**只把 HTML 上传到 GitHub Pages 无法运行双人房间服务**；GitHub Pages 仍可展示原研究站。

### 一次完整的桌面试用

1. 输入昵称，选择珊瑚或青苔样例客厅，点击“创建双人房间”。
2. 复制邀请链接，在另一个浏览器窗口或设备打开；点击“查看”，勾选入场同意，再接受邀请。
3. 点击画面，用 `W/A/S/D` 移动、`Q/E` 转身；拖动画面仅改变观察角度。两端交换的是真实网络消息，桌面动作来源仍是键鼠。
4. 点击播放、暂停或拖动进度，观察另一端跟随 24 秒测试片的共享播放时钟。测试片是仓库自带的原创合成素材。
5. 选择“仅语音”或“开音视频”才会请求设备权限。“仅语音”会关闭已开启的视频；“开音视频”需要麦克风与摄像头权限。
6. 两端各自允许触碰请求，再各点“靠近对方”和“伸出右手”。接收者在 5 秒内选择“接受这一次”，默认看见一次视觉回应。
7. 点击“立即停止”，空间、播放和设备在本机立即停止，同时通知对端。解除暂停后，触碰权限和设备不会自动恢复。
8. 离开后，麦克风、摄像头与触碰输出停止；主场离开会结束整个房间。

同机两个标签可检查会话与播放同步，但失焦的桌面标签会主动停止追踪。要手动验证双人触碰，请使用两个保持前台的设备；自动协议测试不受这个 UI 限制影响。

### 两台设备与公网

两台设备要连接同一个 Node 服务。`HOST` 可配置为 `0.0.0.0`，`PORT` 默认 5173。邀请链接沿用当前浏览器的主机地址，因此另一台设备无法使用发起者的 `127.0.0.1` 链接。

摄像头、麦克风和 WebXR 在非 localhost 环境通常要求 HTTPS；跨网络 WebRTC 还可能需要 TURN。示例配置见 [.env.example](.env.example)。它不会自动加载，使用 Node 的环境文件入口：

```bash
# 先复制 .env.example 为 .env，并填写自己的运行参数
node --env-file=.env --import tsx server/index.ts --production
```

反向代理需要转发 WebSocket Upgrade，并让服务端看到正确 Host；特殊部署的允许来源见 [协议文档](docs/PROTOCOL.md)。尚未完成真实跨城市／跨运营商测试，不承诺只靠房间码即可任意跨网通话。

### 可选容器入口

仓库提供 [Dockerfile](Dockerfile)，包含构建和服务运行步骤：

```bash
docker build -t rove-prototype .
docker run --rm -p 8080:8080 rove-prototype
```

容器配置尚未在本次环境执行构建，不能把该命令列为已验证的部署。容器内使用非 root 用户运行。

## 当前能力与边界

| 能力 | 实现状态 | 证据边界 |
|---|---|---|
| 双人房间与邀请 | 已实现 | 真实 HTTP/WebSocket 测试 |
| 头部、双手同步 | 已实现 | 桌面控制点；不是摄像头动作捕捉 |
| 共享播放时钟 | 已实现 | 24 秒本地样片；没有接影视平台 |
| WebRTC 音视频 | 已实现 | 真正浏览器 API；尚需双浏览器实测 |
| 逐次触碰确认 | 已实现 | 接收、拒绝、撤回、过期及停止均进入协议 |
| 视觉触碰 | 已实现 | 视觉模拟，不产生实体触感 |
| 游戏手柄振动 | 适配器已实现 | 需要用户开启与兼容设备；硬件未实测 |
| WebXR AR/VR | 输入适配代码已实现 | 实体头显未实测，不包含真实房间配准 |
| 房间扫描／真人重建／腕带 | 未实现 | 下一阶段工作 |
| EEG／EMG 与梦境交互 | 未实现 | 保留为远期研究材料 |

## 验证

```bash
npm run typecheck
npm test
npm run build
# 或运行以上三项
npm run check
```

测试分别覆盖真实后端连接、适配器异步取消，以及用 DOM 环境检查的客户端生命周期；具体数量、环境和限制见 [docs/VALIDATION.md](docs/VALIDATION.md)。使用模拟设备的测试不等于真实硬件验收。

应用内“连接与实验记录”可导出本页诊断 JSON，包含服务端往返时延、姿态包计数、播放时钟偏差、RTP 音频字节和事件。不包含录音、录像、邀请凭据或原始姿态坐标。

**往返时延不是动作到画面、也不是触碰到执行器的端到端延迟。** 这些指标后续需要实际设备与统一测量方法。
